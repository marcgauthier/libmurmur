# Storage porting checklist: P1e (kill Go key callbacks) then P2 (offline tools + registration native)

Scope: `deps/murmur/open.{h,cc}`, `deps/murmur/vfs.cc`, `clients/go/bindings/nvfs/nvfs.go`, `clients/go/pkgs/storage/*.go`, `clients/go/pkgs/murmur/*.go`.

## P1e status: LANDED (2026-10-30, design differs from §2 below — §1/§2 kept as history)

Landed design (no `WithKey` entry points; keyless open + lazy refresh instead):

- `PRAGMA key='<64 hex>'` (`serveKeyLocked`, write-only: reads answer
  empty): stages the master in `OpenStore::stagedMaster` and provisions
  the codec. Same key twice = OK; different key once keyed = MISUSE;
  malformed = ERROR; wrong key on a sealed store = CORRUPT. Allowed
  on read-only connections (reads need keys).
- Stores open KEYLESS (`createStore` provisions nothing; envelope
  retained in `OpenStore::keyringEnv`; `db` is `atomic<NvDb*>`, null
  until keyed). `provisionLocked` ports `openKeysFor` exactly (incl.
  master→passphrase fallback, `ByID`-ignores-active, every ring-open
  error → CORRUPT) via the in-tree C++ keyring flat API; staged
  cipher/compression apply at provision.
- VFS files tolerate null db: keyless reads return zeros + SHORT_READ
  (the only unlocked read SQLite performs is the direct, uncached
  open-time header probe, so this cannot poison the pager cache);
  keyless size = 0; keyless lock/write/truncate = IOERR (fail fast,
  no busy-spin); first op after keying refreshes via `nvEntryDb`
  (new `open.h` API) and caches. Shell holders re-fetch once via
  `nvfs.KeyStore` (PRAGMA key + `StoreDb` refresh).
- `sealLocked` is fully native (`murmur_kr_create` + trial open;
  explicit per-call master else staged; keyless seals provision
  first; successful explicit-master seal updates the staged master).
  Deleted: `nvOpenGo`/`nvSealGo` exports + decls + blob protocols,
  `SetKeyHooks`, `openKeysFor`/`sealFor`, the `openKeys` global stash
  + `Set/Clear/LookupOpenKey`, `VFSConfig.OpenKey`, `crypto/rand`
  from `native.go`.
- Go key flows: `OpenDir` = `OpenStoreRef` → `KeyStore` → `openShell`;
  `OpenLive` same (wrong key on a live store = fail fast);
  `murmur.Open` runs `PRAGMA key` from the registered master first.
  Per-shell keys (`shellKeys`, recorded by `openShell`, dropped at
  `Close`) replaced the global stash for ring reloads and
  `storeExtFor`. Remaining `//export`s: the 3 replication-extension
  ones (`nvMurmurExtFileGo`/`nvMurmurExtStoreGo`/`nvCloseFileGo`).
- Pinned by: rewritten `TestControlPlaneWrongKey` (wrong→CORRUPT,
  keyless read fails, right key reads, second key→MISUSE, malformed
  rejected), keyed-harness `openKeyed` across `vfs_test.go` /
  `control_sql_test.go`, plus a pure-C lifecycle proof
  (open→key→write→seal→reopen→wrong→right, no Go).
- P2 notes below are still current; `open.cc`/`nvfs.go` line numbers
  predate P1e (symbols unchanged: `sealLocked`, `serveLocked`,
  `openShell`, `OpenLive`, `shellCanons`, `storeExtFor`).
